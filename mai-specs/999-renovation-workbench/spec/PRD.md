# 装修项目工作台 PRD

> Feature 999 · standard · 模板 ../../_templates/PRD.tmpl.md · 有效验收来源为本文。需求来自本次会话。

## 背景、用户和范围

面向中国大陆住宅家装与局部改造的小团队。负责人在桌面看图出单，在现场用手机记账。首版提供同一团队工作台内可独立使用的报价和项目账，并允许对同一项目串联。地区和清包、半包、全包差异由团队单价、施工说明和供料方表达。范围包括内部对账及对外单据导出。报税、开票、法定账簿、付款执行和电子签署在范围外。

[中消协投诉情况](https://legalinfo.moj.gov.cn/pub/sfbzhfx/zhfxfzzx/fzzxyw/202602/t20260206_531470.html) · [住宅装修合同示范文本](https://htsfwb.samr.gov.cn/View?id=e3f51fe0-cdb4-4382-bfa4-64e3c784b9c6) · [装饰工程工程量计算标准](https://zjw.beijing.gov.cn/bjjs/gczj14/xhlbz/ys20/cjwd33/743981704/index.shtml)

## 交互与业务流程

桌面布局如下。窄屏按顺序纵向排列。报价和账目都是项目内的页签，通过表单可以独立操作。聊天提供同一业务记录的快捷录入和查阅。

```text
装修项目工作台                    项目选择 | 新建项目
[报价] [项目账]
报价：聊天上传资料 → Agent 补问和确认 → 工具生成报价 → 页面查看与下载
项目账：约定金额 | 已收 | 待收 | 待付   [记一笔]
       收款、费用、付款及垫资记录 → 导出对账表
```

## 验收条件

| ID | 可观察结果 |
|---|---|
| AC-01 | 项目可以直接建立并开始记账，也可以先做报价。关闭页面或重启后，按项目找回数据。非该团队的访问者读不到图纸、原始凭据或账目。 |
| AC-02 | 上传支持的二维 DWG 或 DXF，选择图纸布局或测量范围，核对单位或按已知长度校准。在图上选取边界，对照面积或长度。未闭合、单位不明或图纸不全时提示补图、校准或手填。 |
| AC-03 | 可以导入带明确表头的 Excel 价表或已有报价，也能手填。每项数量显示图算、手填或暂估，说明供料方和报价口径，金额可复算。确认后锁定版本，客户版可导出。 |
| AC-04 | 增减项单独记录并留存确认依据，未确认增减项不进入合同汇总。客户报价与内部台账分别导出。 |
| AC-05 | 分期回款可按期款核对。登记材料或人工费用、分次付款和团队垫资，报销只结清垫资。重复提交不会重复入账，凭据疑似重复有明确提示。 |
| AC-06 | 凭据可以上传。若模型能提取，金额、日期、对象先成为待确认记录。确认后入账，可导出明细和凭据供会计使用。 |
| AC-07 | 桌面能看图和编辑报价，390 CSS px 下主要记账操作可达。加载、空、失败及重新执行可辨识，金额错误和未确认数据不会被当成成功。 |
| AC-09 | 业主侧 Web 聊天可上传当前会话的 DWG、DXF、Excel 或文本；模型可获取边界和已提供的报价信息，只针对缺项补问。用户确认后工具生成有版本的报告，链接打开对应项目和报价明细。确认签约与发送给客户由用户决定。 |
| AC-10 | 项目首页显示当前账目及待处理。用户可在窄屏录收款、付款、欠款或垫资，从待报销直接预填结款。资金账户互转独立于项目成本与应收，未知期初显示已登记流水。 |
| AC-08 | 用真实项目 DWG、价表和收付款样本完成图纸算量、出单、增项、回款和垫资对账。再用无 CAD 的项目验证独立记账。真实样本未提供时，开发夹具用于回归，真实业务验收保持待验证。 |

## 产品假设

首版部署在一个现有 DSH Web owner 的授权范围内，每个 Harness home 对应一个团队工作台。团队的独立成员账户、地域价格库和外部在线签署是后续产品决定。原始图纸和支付凭据由 Host 保存，只将完成用户要求所需的字段交给模型。
