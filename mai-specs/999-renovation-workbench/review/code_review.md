## 范围

比较基线是 `4b399c39a6`。评审范围为新增目录 [plugins/renovation-workbench](../../../plugins/renovation-workbench)，工作区先前的 Git 忽略规则和 Agent 配置不在范围内。

## 已修复

- 图算来源原先只由界面提供。Host 现在检查图纸归属、读取边界和校准，并在保存前复算。
- 价表原先随页面关闭丢失。现在通过 SQLite 持久化团队价表，无效行不会替换现有价表。
- 金额预览与锁定共用同一 Host 算法。
- 已发布的 DSH 0.2.2-rc.5 自定义 HTTP 路由不给 Handler 传已认证的 Peer。插件在该路径调用 Connection 自带的认证接口，缺少有效凭据即拒绝。实际 DSH Web 验证未登录拒绝、登录后侧栏入口和收款。
- 同一笔可关联多份凭据。重复提交使用操作 ID，重复凭据使用项目内内容指纹。

## 待验证或未完成

- LibreDWG 0.14 在生成的 DWG 中实算 12 ㎡ 与 14 m，真实住宅工程图适配待验证。复杂图层、外部参照和天正专有对象仍需转换或手动处理。
- 本地凭据草稿可以手工确认，实际 Tesseract 中文图片识别未验证。真实模型的补问质量仍待验证。
- 真实项目样本未提供，验收留待运行时与资料齐备后执行。

## 产品交互与聊天接入复评

普通聊天工具从已提交的所有者会话读取文件，报告与图纸引用原子保存。浏览器烟测发现 DSH Markdown 会把相对链接渲染成文字，修正为 DSH Web 的绝对地址并复验。账户迁移保留旧记录，旧收付继续参与项目汇总，有来源账户的实际收付才计入资金流水。
